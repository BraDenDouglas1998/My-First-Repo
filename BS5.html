Bootstrap is a front-end framework that provides ready-made CSS classes and JavaScript components for responsive websites.

1. Getting Started

This page loads Bootstrap 5 using the CSS and JavaScript CDN links in the document head and just before the closing body tag.

Mobile-first: The viewport meta tag helps the page scale correctly on phones and tablets.

Bootstrap's CSS classes are added directly to HTML elements, for example class="text-primary".
